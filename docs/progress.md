# ЛР 1. Старт проекта на React и TypeScript

Создан каркас приложения «Каталог фильмов и сериалов» на React + TypeScript + Vite.
Начальный экран содержит название, описание и пустой раздел списка записей.

## Шаги проверки

1. `npm ci` в папке frontend — зависимости устанавливаются без ошибок.
2. `npm run dev` — сервер запускается, экран открывается на localhost:5173.
3. Ошибок в терминале и в консоли браузера нет.
4. Текст читается на узком экране без горизонтальной прокрутки.
5. `npm run build` — проверка типов и сборка проходят успешно.
6. `npm run preview` — готовая сборка открывается и отображает экран.

Коммит ЛР 1: <3a85b5b>

# ЛР 2. Страницы приложения и навигация

Добавлены типы и демонстрационные данные, компонент карточки, страницы
списка, подробностей, добавления и неизвестного адреса, общий layout
и маршруты на react-router.

## Шаги проверки

1. Список показывает пять записей, карточки открываются по ссылке.
2. Прямое открытие адреса карточки и обновление страницы работают.
3. Адрес /unknown показывает сообщение о неизвестной странице.
4. Адрес /media/missing показывает сообщение об отсутствующей записи.
5. Пустой массив данных выводит сообщение о пустом списке.
6. npm run build и npm run preview проходят без ошибок.

Коммит ЛР 2: 557ec67

# ЛР 3. Формы и локальное состояние

Список записей перенесён в состояние App. Добавлены создание, редактирование
и удаление записей через общую форму, проверка ввода и фильтр по статусу
просмотра. Данные хранятся в памяти приложения.

## Шаги проверки

1. Создание записи: открывается её карточка, запись появляется в списке.
2. Редактирование: изменения видны в карточке и в списке, id сохраняется.
3. Отмена в форме не меняет сохранённую запись.
4. Проверка ввода: короткое название, пустой год и оценка вне диапазона 1–10
   показывают сообщение, введённые поля сохраняются.
5. Фильтр по статусу и его сброс работают, пустой отбор показывает сообщение.
6. Удаление с подтверждением возвращает к списку, адрес удалённой записи
   показывает сообщение об отсутствии.
7. После обновления страницы возвращается демонстрационный набор.
8. npm run build и npm run preview проходят без ошибок.

Коммит ЛР 3: 6f31558
