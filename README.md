# Каталог фильмов и сериалов

Учебное веб-приложение для курса «Практический курс веб-разработки».

## Автор

Бабаджанян Арташ Григорьевич, группа ФТ24ДР62ПИ1.

## Тема и основной сценарий

Каталог фильмов и сериалов помогает зрителю вести личный список
просмотренного и запланированного. Пользователь добавляет фильм или
сериал, отмечает статус просмотра, ставит оценку и добавляет
понравившееся в избранное.

## Стек

React, TypeScript, Vite. Node.js 24.21.0.
Позже будут добавлены Supabase и backend на Node.js.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Каталог фильмов и сериалов с навигацией между страницами.
Адреса приложения:

- `/media` — список записей
- `/media/:id` — подробности записи
- `/media/new` — заглушка добавления записи

Записи демонстрационные и хранятся в коде приложения.

## Текущие ограничения

# ЛР 3. Формы и локальное состояние

Список записей перенесён в состояние App. Добавлены создание, редактирование
и удаление записей через общую форму, проверка ввода и фильтр по статусу
просмотра. Данные хранятся в памяти приложения.

## Шаги проверки

1. Создание записи: открывается её карточка, запись появляется в списке.
2. Редактирование: изменения видны в карточке и в списке, id сохраняется.
3. Отмена в форме не меняет сохранённую запись.
4. Проверка ввода: короткое название, пустой год и оценка вне диапазона 1–10
   показывают сообщение, введённые поля сохраняются.
5. Фильтр по статусу и его сброс работают, пустой отбор показывает сообщение.
6. Удаление с подтверждением возвращает к списку, адрес удалённой записи
   показывает сообщение об отсутствии.
7. После обновления страницы возвращается демонстрационный набор.
8. npm run build и npm run preview проходят без ошибок.
