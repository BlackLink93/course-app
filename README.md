# Каталог фильмов и сериалов

Учебное веб-приложение для курса «Практический курс веб-разработки».

## Автор

Бабаджанян Арташ Григорьевич, группа ФТ24ДР62ПИ1.

## Тема и основной сценарий

Каталог фильмов и сериалов помогает зрителю вести личный список
просмотренного и запланированного. Пользователь регистрируется, добавляет
фильм или сериал, отмечает статус просмотра, ставит оценку и добавляет
понравившееся в избранное. Записи хранятся в Supabase и видны только
их владельцу.

## Стек

React, TypeScript, Vite, Supabase (PostgreSQL). Node.js 24.21.0.
Позже будет добавлен backend на Node.js.

## Запуск

1. Создайте проект Supabase и выполните в SQL Editor по порядку:
   `supabase/migrations/202611082300_initial_schema.sql`,
   `supabase/seed.sql`,
   `supabase/migrations/202611082310_media_entries_owner_policies.sql`.
2. В Authentication → URL Configuration добавьте адрес Vite
   (например `http://localhost:5173`) в Redirect URLs.
3. Скопируйте `frontend/.env.example` в `frontend/.env.local` и укажите
   URL проекта и publishable key.
4. Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Переменные окружения

- `VITE_SUPABASE_URL` — URL проекта Supabase.
- `VITE_SUPABASE_PUBLISHABLE_KEY` — publishable key.

Значения хранятся только в `frontend/.env.local`, который не попадает в Git.
Secret key, service_role и пароль базы во frontend не используются.

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Регистрация, вход и выход, личный каталог в Supabase с фильтром по статусу.
Адреса приложения:

- `/auth` — вход и регистрация
- `/media` — список записей с фильтром по статусу просмотра
- `/media/:id` — подробности записи, удаление с подтверждением
- `/media/new` — добавление записи
- `/media/:id/edit` — редактирование записи

Все адреса `/media` доступны только после входа.

## Схема данных и доступ

- `genres` — публичный справочник жанров. Читают все, изменять из браузера нельзя.
- `media_entries` — личные записи (`owner_id` → `auth.users.id`,
  `genre_id` → `genres.id`). Читает, создаёт, изменяет и удаляет только
  владелец: четыре политики RLS с условием `auth.uid() = owner_id`.

SQL схемы и прав — в `supabase/migrations`, начальные жанры — в `supabase/seed.sql`.
Скрытие маршрутов в интерфейсе (`RequireAuth`) — удобство, настоящую защиту
выполняют RLS и права PostgreSQL.

## Источник справочника жанров

Жанры загружаются из таблицы Supabase `genres` через сервис
`frontend/src/services/genres.ts`, который проверяет ошибку запроса и структуру
ответа. В записи хранится id жанра, в форме показывается его название.
Пока справочник не загружен или жанр не выбран, сохранить запись нельзя.
Кнопка «Обновить справочник» загружает жанры заново, не стирая черновик.
