# Каталог фильмов и сериалов

Учебное веб-приложение для курса «Практический курс веб-разработки».

## Автор

Бабаджанян Арташ Григорьевич, группа ФТ24ДР62ПИ1.

## Тема и основной сценарий

Каталог фильмов и сериалов помогает зрителю вести личный список
просмотренного и запланированного. Пользователь добавляет фильм или
сериал, отмечает статус просмотра, ставит оценку и добавляет
понравившееся в избранное.

## Стек

React, TypeScript, Vite. Node.js 24.21.0.
Позже будут добавлены Supabase и backend на Node.js.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Каталог фильмов и сериалов с навигацией, формами и локальным состоянием.
Адреса приложения:

- `/media` — список записей с фильтром по статусу просмотра
- `/media/:id` — подробности записи, удаление с подтверждением
- `/media/new` — добавление записи
- `/media/:id/edit` — редактирование записи

## Источник справочника жанров

Жанры загружаются по HTTP из файла `frontend/public/demo/genres.json`,
который раздаёт Vite по адресу `/demo/genres.json`. Запрос выполняет
сервис `frontend/src/services/genres.ts`, он проверяет HTTP-статус
и структуру JSON. В записи хранится id жанра, в форме показывается его
название. Пока справочник не загружен или жанр не выбран, сохранить
запись нельзя. В ЛР 5 источник справочника будет заменён на Supabase.

## Текущие ограничения

Основные записи хранятся только в памяти браузера: после обновления
страницы возвращается демонстрационный набор из `src/data/media.ts`.
Supabase, авторизация и Node API появятся в следующих лабораторных работах.
